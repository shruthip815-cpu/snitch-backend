# Snitch E-Commerce Backend

This is the **backend part of my Snitch E-Commerce project**.

I built this project while learning **Backend Development** with Node.js, Express.js and MongoDB.

## What I worked on

* User Registration and Login
* JWT Authentication
* Access Token and Refresh Token
* User and Seller Roles
* Product APIs
* Product Create, Update and Delete
* Product Image Upload
* Product Validation
* Cart APIs
* Seller List API
* Seller Unlist API

## Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcrypt
* Express Validator
* ImageKit

## About the Project

This project helped me understand how different backend APIs work together in an E-Commerce application.

I worked on the backend step by step as part of my backend development learning journey.

**This repository contains only the backend implementation.**
